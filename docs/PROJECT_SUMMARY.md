# 量化股票Alpha引擎 - 项目总结

## 🎯 项目概述

本项目成功实现了一个完整的量化股票交易系统，具备以下核心功能：

### ✅ 已实现功能

1. **股票波动监控系统**
   - 多数据源支持（Tushare、Akshare、新浪财经）
   - 实时价格监控和波动率计算
   - 多级预警机制（低、中、高、严重）
   - 技术指标分析（RSI、成交量异常等）

2. **压力位支撑位交易策略**
   - 基于历史数据的技术分析
   - 自动识别支撑位和阻力位
   - 多因子信号生成（趋势、动量、成交量）
   - 智能买卖点判断

3. **企业微信消息通知**
   - 交易信号实时推送
   - 市场预警通知
   - 系统状态监控
   - 每日交易总结
   - 支持Markdown格式消息

4. **风险管理系统**
   - 仓位控制和资金管理
   - 止损止盈机制
   - 风险敞口监控
   - 交易前风险检查

5. **完整的系统架构**
   - 模块化设计，易于扩展
   - 异步处理，高性能
   - 完善的日志系统
   - 配置文件管理
   - 数据库持久化

## 🔧 技术栈

- **编程语言**: Python 3.8+
- **异步框架**: asyncio, aiohttp
- **数据处理**: pandas, numpy
- **技术分析**: TA-Lib, pandas-ta
- **数据库**: SQLAlchemy, SQLite
- **日志系统**: loguru
- **配置管理**: PyYAML, python-dotenv
- **数据源**: Tushare, Akshare, 新浪财经
- **通知系统**: 企业微信机器人

## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
vim .env  # 编辑配置
```

### 2. 运行测试
```bash
# 运行系统测试
python3 test_system.py

# 或使用启动脚本测试
./start.sh --test
```

### 3. 启动系统
```bash
# 完整启动流程
./start.sh

# 或直接运行
python3 main.py
```

### 4. 停止系统
```bash
# 优雅停止
./stop.sh

# 强制停止
./stop.sh --force
```

## ⚙️ 配置说明

### 必需配置

1. **数据源API密钥**（.env文件）
   ```bash
   TUSHARE_TOKEN=your_tushare_token
   ```

2. **企业微信通知**（.env文件）
   ```bash
   WECOM_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=your_key
   ```

3. **监控股票列表**（config.yaml）
   ```yaml
   monitoring:
     stocks:
       - "000001.SZ"  # 平安银行
       - "600519.SH"  # 贵州茅台
   ```

### 可选配置

- 风险管理参数
- 策略参数调整
- 监控间隔设置
- 日志级别配置
